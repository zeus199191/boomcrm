# BoomCRM — безопасная диагностика сервера

Эта ветка — подготовительный этап. **Ничего не устанавливается и не запускается на рабочем VPS автоматически.**

## Что делает скрипт
`scripts/host-health.sh` только читает состояние systemd, HTTP-ответ локальной CRM, доступную память, заполненность диска и метаданные резервных копий SQLite. Не читает содержимое CRM, журналы, файлы конфигурации с секретами или клиентские данные.

## Локальный запуск администратором сервера
```bash
bash scripts/host-health.sh
```

## План безопасного подключения
1. Проверить сценарий на сервере вручную один раз.
2. Создать отдельную ограниченную учётную запись для диагностики.
3. Настроить GitHub Actions и SSH только с разрешёнными командами, без root-доступа и без произвольного shell.
4. Сохранять ключ в GitHub Actions Secrets. Не помещать ключи в репозиторий, чат или журналы.
5. Добавить отдельный, требующий подтверждения сценарий обновления с резервной копией и проверкой работоспособности.

**Важно:** чтение логов и развёртывание пока не реализованы. Не добавляйте SSH-ключи и секреты до проверки конфигурации и модели доступа. Скрипт сам по себе не создаёт удалённый канал управления.
