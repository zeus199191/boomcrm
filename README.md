# CRM «Бумсистем» — студия автозвука и тюнинга

Веб-CRM, которая работает на вашем сервере. Открывается в браузере с компьютера и с телефона.
Без абонентской платы и без внешних зависимостей: Node.js и встроенная база SQLite.

## Что умеет

| Раздел | Возможности |
|---|---|
| **Сайт · Автозвук** | Отдельная страница /avtozvuk (меню «Автозвук», кнопка «Подробнее» на плитке): соревновательный опыт в классе SQ, из чего собираем систему (фронт, сабвуфер, усилители, DSP, источник, провода), бренды Brax, Helix, Match, Audison, Hertz, Focal, Morel, JL Audio, Recoil Audio (+ Hellion, Madbit, Контур-Аудио, Resolut, GoldHorn, Aura, DL Audio, Alphard Group, Dynamic State) — стена логотипов 6×3 — загружаются в Настройки → «Логотипы брендов на сайте» (Audison, Hertz, Recoil сервер скачивает сам), этапы работы, заявка с отмеченным «Автозвук» |
| **Сайт** | Лендинг ателье на главной странице сервера: слоган, фото-карточки услуг (бесплатные фото Unsplash), блок «надёжность», витрина «Автосигнализации StarLine и Pandora» (вкладки по маркам, актуальные розничные цены из каталога, кнопка «Установить» подставляет модель в заявку; что показывать — галочка «Показывать на сайте» в карточке товара, фильтр «На сайте» на Складе), отзывы клиентов с 2ГИС с рейтингом (вносятся в Настройках → «Отзывы на сайте»), порядок работы, контакты из Настроек, форма заявки (попадает в «Заявки» с источником «Сайт» и уведомлением в MAX/Telegram). Кнопка «Вход» → CRM по адресу `/crm`. Выключается в Настройках |
| **Главная** | Касса за день и за месяц, записи на сегодня, машины в работе, долги клиентов, заканчивающиеся товары, новые заявки |
| **Журнал записи** | Как привычная Excel-таблица: дни × посты 1–6, авто стоит на посту несколько дней, заметки в ячейках с цветами, импорт старого журнала. Плюс вид «по часам» |
| **Предварительный расчёт** | Бланк расчёта: работы и товары из прайса/склада или вписанные вручную, печать с пометкой «Цены актуальны на дату обращения». Не попадает в журнал, не списывает склад, не создаёт долгов. Кнопка «Клиент согласен — в заказ-наряд» |
| **Заказ-наряды** | Статусы: новый → записан → в работе → ждёт запчасти → готов → выдан. Работы из прайса, товары со склада, мастер на каждую работу, скидка, гарантия, оплаты и возвраты, история изменений и комментарии |
| **Руководители** | Отдельная вкладка в «Сотрудниках»: часы за месяц из графика, остаток всех денег, обязательные расходы месяца (аренда, кредит, налог, свои строки), нормочас = остаток ÷ часы всех руководителей, доход по часам минус равная доля обязательных расходов = чистый доход каждого. Кнопка «Выплатить всем» — одна операция «Зарплата руководителей» в Финансах |
| **Фото приёмки** | Фото автомобиля с камеры телефона или с ПК (автоматически сжимаются), просмотр и скачивание, отправка выбранных фото в MAX мастеру, сотрудникам или в общий чат с пометкой заказа. Файлы хранятся в `/var/lib/boomcrm/photos/` |
| **Печать** | Акт приёма автомобиля (схема повреждений: 5 видов седана, личные вещи, перечень работ), заказ-наряд, акт выполненных работ (сумма прописью), гарантийный талон с датой окончания по каждой позиции |
| **Клиенты** | Поиск по имени, телефону, госномеру, VIN и марке. Несколько авто у клиента, заметка «что установлено», постоянная скидка, источник, сумма покупок, выгрузка в Excel |
| **Заявки** | Заявки с сайта, из Тильды и квизов, ручной ввод. Заявка превращается в заказ в один клик, существующий клиент находится по телефону |
| **Склад** | Загрузка прайса поставщика .xlsx (закупка — VIP дилер, продажа — розница), вставка из Excel, остатки, закупка и наценка, приход по накладной (средняя себестоимость), корректировки, журнал движений. Списание при выдаче авто, возврат при отмене |
| **Услуги** | Прайс по категориям: цена, время и гарантия. Заранее заполнен типовыми работами автозвука |
| **Финансы** | Остатки по кассам «Наличные / Карта / Счёт» с отчётом за период, способы оплаты: наличные, перевод на карту (без эквайринга), терминал (на расчётный счёт, эквайринг 2% автоматически нашим расходом; процент — в Настройках), обналичивание (со счёта и с карты, с комиссией), перемещения, сверка фактических остатков. Касса (приходы, расходы, статьи), график по дням, способы оплаты, выручка, себестоимость и валовая прибыль, топ услуг и товаров, источники клиентов |
| **Банк (Альфа-Банк)** | Финансы → Банк: операции по расчётному счёту загружаются через Alfa API (каждые 30 минут) или файлом выписки 1С и разносятся автоматически: оплаты заказов (по «БС-…» в назначении), контрагенты по ИНН, возмещение по терминалу, аренда, налоги, кредит, комиссии, снятие наличных, связь с уже внесёнными операциями. Остальное — вручную. Подключение: Настройки → «Альфа-Банк (Alfa API)» |
| **Товар в долг** | При добавлении товара в заказ-наряд видно: на складе, в резерве под другие открытые заказы и свободно. Если свободного не хватает — галочка «В долг» ставится сама: товар оприходуется от выбранного поставщика под этот заказ, и перед ним записывается долг. Галочку можно поставить и вручную. У уже добавленного товара есть кнопка «＋ В долг у поставщика» и «отменить долг» |
| **Маркетинг** | Раздел для руководителей: **Аналитика** (выручка, заявки и конверсия, новые и повторные клиенты, каналы привлечения с ценой заявки/клиента и ROMI, динамика за 12 месяцев, что приносит деньги, топ работ); **Контент-план** (календарь публикаций по каналам и статусам, банк сезонных идей, темы из выданных заказ-нарядов, ответственный по умолчанию — Александр); **Реклама и бюджет** (расходы по каналам с проводкой в Финансы, окупаемость); **База для рассылок** (давно не были, без сигнализации, с сигнализацией, дни рождения, лучшие клиенты — CSV, телефоны, WhatsApp с шаблоном); **Отзывы** (кого попросить об отзыве в 2ГИС после выдачи); **Инструменты** (UTM-ссылки на сайт — заявка придёт с источником «Сайт · канал», шаблоны сообщений) |
| **Импорт старой базы клиентов** | Клиенты → «⬆ Импорт базы» (или Маркетинг → База → «Загрузить старую базу»): Excel .xlsx или CSV. Колонки (имя, телефон, авто, госномер, дата, сумма, заметки…) определяются по заголовкам, их можно поправить. Журнал записи со свободным текстом в ячейках тоже понимается: телефоны находятся в тексте, машина — из первой строки, имя — если указано рядом, дата — из колонки дат. Только записи с телефоном; дубли по телефону не создаются; последний визит из старой базы учитывается в сегментах рассылок («Давно не были», «С/без сигнализации») |
| **SMS** | Настройки → «SMS-рассылка»: с личного Android-телефона (приложение SMS Gateway for Android, облачный режим — логин/пароль из приложения; SMS уходят с SIM по тарифу) или через SMS.ru. Очередь с паузой между SMS, дневным лимитом и тихими часами. Автосообщения: напоминание о записи накануне, «машина готова», просьба об отзыве после выдачи. Рассылка по сегментам («SMS всем»), SMS в «Отзывах», очередь — Маркетинг → SMS. Отметка у клиента «Не отправлять SMS» |
| **Онлайн-касса Saby** | Касса Нева-01-Ф с программой Saby и терминал Альфа-Банка. При оплате любым способом (наличные, перевод, терминал) с галочкой «Провести через кассу Saby» CRM создаёт по API Saby заказ на сумму (построчно по позициям или одной строкой). Кассир открывает его на кассе в «Заказах» и закрывает нужным способом: картой (Saby сам передаёт сумму на терминал), наличными или безналичными (перевод) — касса печатает чек. Способ оплаты в CRM записывается тот, что выбран при отправке. CRM каждые 20 секунд проверяет заказ и, когда он оплачен, записывает оплату и эквайринг. Ожидающую оплату можно проверить или отменить в карточке заказа. Подключение: Настройки → «Онлайн-касса Saby» (ID приложения, защищённый и сервисный ключ, точка продаж, прайс, позиция «Услуги автосервиса») |
| **Контрагенты** | Поставщики, партнёры, подрядчики: кто кому должен, приход товара в долг, оплаты через кассу, заказы партнёров, акт сверки |
| **Гарантия** | Приём товара от клиента на гарантию (серийный номер, неисправность, комплектность), выбор поставщика, передача поставщику (дата, накладная/трек), возврат и результат (ремонт, замена, возврат денег, отказ), выдача клиенту. Счётчик дней и крайний срок 45 дней. Напоминания в MAX ответственному (по умолчанию Артём) на 30, 40 и 45 день с кнопками смены статуса. Печать акта приёма и акта передачи поставщику. Кнопка «Принять на гарантию» в заказ-наряде |
| **Запись голосом** | Кнопка «🎤 Голосом» на главной и в заказ-нарядах: фраза вида «Алексей, Тойота Филдер 2017, установка сигнализации StarLine E97 на 3 ноября в 11 часов» разбирается на клиента (поиск в базе по телефону или имени), авто, год, дату и время, услугу из прайса (с учётом марки: Япония / Китай / Европа / MB) и оборудование из каталога. Открывается заполненная форма заказа для проверки. Распознавание речи — в Chrome / Яндекс Браузере (нужен HTTPS); в других браузерах — микрофон на клавиатуре телефона |
| **Комплексы** | «Услуги и цены» → «Комплексы»: готовые наборы работ из прайса и товаров со склада (например, «Сигнализация + автозапуск + метка»), у каждой позиции своя цена или текущая из прайса. Создают и редактируют руководители и администратор. В заказ-наряде и расчёте кнопка «📦 Комплекс» добавляет все позиции сразу. На сайт не выгружаются |
| **Прайс для Saby** | «Склад» или «Услуги и цены» → «⬇ Прайс для Saby»: Excel с розничными ценами (товары и/или услуги, ставка НДС на выбор). Колонки: Код товара (Т… — товар, У… — услуга, постоянный), Наименование, Артикул, Раздел, Единица измерения, Цена, НДС, Тип. В Saby: Склад → «+» → Загрузить → Номенклатуру → Из файла; при повторной загрузке — «Только дополнения и изменения» |
| **Зарплата** | % мастеру от работ и % менеджеру от товаров, детализация по заказам, выплата через кассу |
| **Сотрудники** | Роли администратор, руководитель-мастер (те же права, что у администратора), менеджер и мастер. Мастер только просматривает: календарь, свои заказы (без изменений), свою зарплату с расшифровкой; может добавлять фото; статусы, комментарии и уведомления меняют руководители и администратор. График работы на месяц (выходной, отпуск, больничный, отсутствие), учёт часов руководителей-мастеров с итогом за месяц. Отсутствующий мастер помечается «(Н/Р)» при записи и в журнале |
| **Телефон и ПК** | Адаптивный интерфейс; на iPhone и Android ставится как приложение («Поделиться → На экран „Домой“» / «Установить приложение»): свой значок, полный экран, нижняя панель вкладок, вход сохраняется 90 дней с продлением. При узком окне на ПК меню сворачивается в значки |
| **MAX** | Бот студии для сотрудников: привязка по коду, уведомления руководству и мастерам (с кнопками «В работе / Ждёт запчасти / Готово» (кнопки — только руководителям)), «Написать мастеру» из заказа, раздел «Сообщения», общий чат, вечерняя сводка |
| **Telegram** | Сотрудникам: заявки, новые записи, «авто готово», план на завтра в 18:00. Клиентам: напоминание за день и «можно забирать» |

## Установка на сервер (Ubuntu 24, 1 ГБ RAM)

**1. Загрузите архив на сервер.** На Windows откройте «Командную строку» (Win+R → `cmd`) в папке с архивом и выполните:

```
scp boomcrm.tar.gz root@89.125.121.183:/root/
```

Команда спросит пароль root. Вместо командной строки можно использовать WinSCP.

**2. Подключитесь к серверу:**

```
ssh root@89.125.121.183
```

**3. Распакуйте и установите:**

```
tar xzf boomcrm.tar.gz
cd boomcrm
bash install.sh
```

Через 2–4 минуты скрипт покажет адрес и пароль администратора (логин `admin`). По адресу сервера открывается сайт ателье, CRM — по кнопке «Вход» или по адресу `/crm`.

### С доменом и HTTPS (рекомендуется)

Без HTTPS пароли передаются открытым текстом, поэтому для постоянной работы нужен домен.

1. У регистратора домена создайте A-запись: `crm.ваш-домен.ru → 89.125.121.183`.
2. Подождите 10–30 минут, затем выполните:

```
cd /root/boomcrm
bash install.sh crm.ваш-домен.ru  ваша@почта.ru
```

Сертификат Let's Encrypt бесплатный и продлевается автоматически.

### Часовой пояс

По умолчанию выставлен Иркутск. Для другого пояса укажите его при запуске: `TZ_NAME=Europe/Moscow bash install.sh`.

## Первые шаги после входа

1. **Пароль**: нажмите «Пароль» внизу меню и смените пароль администратора.
2. **Настройки**: заполните название, адрес, телефон, реквизиты для документов и список боксов.
3. **Сотрудники**: заведите мастеров и менеджеров, укажите их проценты.
4. **Услуги и цены**: поправьте прайс под себя.
5. **Склад**: добавьте товары или оформите приход.
6. **Telegram**: подключите бота по инструкции в «Настройках».
7. **Сайт**: в «Настройках» есть готовый код формы заявки.

## Обслуживание

| Задача | Команда |
|---|---|
| Статус | `systemctl status boomcrm` |
| Логи | `journalctl -u boomcrm -n 100` |
| Перезапуск | `systemctl restart boomcrm` |
| Обновление | Настройки → «Обновить CRM» (или из консоли: `curl -sL https://raw.githubusercontent.com/zeus199191/boomcrm/main/go.sh \| bash`) |
| Домен | Настройки → «Подключить домен» (после A-записи на IP сервера) |
| Сброс пароля | `cd /opt/boomcrm && sudo -u boomcrm CRM_DATA=/var/lib/boomcrm node scripts/reset-password.js admin НовыйПароль` |
| Ручной бэкап | `cd /opt/boomcrm && sudo -u boomcrm CRM_DATA=/var/lib/boomcrm node scripts/backup.js` |

- **Бэкапы**: каждую ночь в 03:30 копия кладётся в `/var/lib/boomcrm/backups/`, хранятся 30 последних. Включите и бэкап VPS у хостера.
- **Восстановление**: `systemctl stop boomcrm`, скопируйте нужный бэкап в `/var/lib/boomcrm/crm.sqlite`, выполните `chown boomcrm: /var/lib/boomcrm/crm.sqlite`, затем `systemctl start boomcrm`.
- **Копия себе**: Настройки → «Скачать копию базы». Файл открывается программой DB Browser for SQLite.

## Заявки с сайта (API)

```
POST https://crm.ваш-домен.ru/api/public/lead
Заголовок: X-API-Key: <ключ из Настроек>     (или параметр ?key=...)
Тело (JSON или форма): name, phone, car, message, source
```

## Структура

```
server.js            HTTP-сервер, роутинг, печать
lib/db.js            схема базы и начальные данные
lib/api.js           всё API
lib/auth.js          пароли (scrypt), сессии, роли
lib/telegram.js      бот, уведомления, напоминания
lib/print.js         печатные формы
public/              интерфейс (HTML/CSS/JS, без сборки)
scripts/             бэкап, сброс пароля
install.sh           установка и обновление
```
